# Bike Share Toronto visualizer

An animated map of one day of Bike Share Toronto trips (Thursday, August 13, 2026: 45,320 trips), built with Vite, React, deck.gl's `TripsLayer` and MapLibre GL.

See [docs/map-visualization-options.md](docs/map-visualization-options.md) for the dataset write-up and other map ideas.

## Run

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in dist/
```

URL options: `?t=08:30` starts the clock at 08:30, and `?paused` starts paused. Press Space to play or pause, and click or drag the timeline to scrub.

## Export a video

Open [http://localhost:5173/?video](http://localhost:5173/?video) and press **Export video**. The page shows the loop as it will be saved. The file is a greyscale top-down view of Toronto, H.264 MP4, 1920 × 1080 at 30 fps, with about 33 minutes of the day per second. Only the time and "bike share rides" appear on it. Export needs a browser with WebCodecs (current Chrome, Edge or Safari). Add `&speed=1.2` to any video URL to play the day that much faster.

The loop runs 04:00 to 04:00, the quietest time of day, and rides that cross the join wrap around. Tails are shorter around downtown so rides stay distinct there. Size, framing, speed, bitrate and tail lengths are constants at the top of [src/videoFrames.ts](src/videoFrames.ts).

For a 2017 vs 2026 side-by-side on one map and clock, open [http://localhost:5173/?compare](http://localhost:5173/?compare). It compares Thursday, August 10, 2017 with Thursday, August 13, 2026.

Two more versions add a running total for the day: `?co2` (estimated CO₂ saved) and `?prompts` (the same saving as a number of AI prompts). [docs/co2-and-ai-prompts.md](docs/co2-and-ai-prompts.md) explains the estimate and its sources; the assumptions are constants in [src/videoFrames.ts](src/videoFrames.ts).

The video has no credit line, so credit the map and data wherever you post it: © OpenStreetMap contributors, © CARTO, City of Toronto Open Data.

## Rebuild the data for another day

`public/data/day-2026-08-13.json` is generated by [scripts/build_day.py](scripts/build_day.py):

```sh
python -m venv .venv && .venv/bin/pip install pandas osmnx scipy scikit-learn shapely
# Download a year from https://open.toronto.ca/dataset/bike-share-toronto-ridership-data/
.venv/bin/python scripts/build_day.py bikeshare-ridership-2026.zip 2026-08-13
```

The script:

1. Reads that day's trips and drops trips under 60 s or over 3 h, trips with no end station, and round trips.
2. Joins station IDs to coordinates from the live GBFS `station_information` feed. Stations no longer in the feed are dropped (886 trips on Aug 13).
3. Routes every station pair on the OpenStreetMap bike network (OSMnx + SciPy Dijkstra). The network download is cached in `.cache/`; the first run takes a few minutes.
4. Writes routes once per station pair, plus a compact trip list. The browser spreads each trip's start-to-end time along its route by distance.

`public/data/day-2026-08-13.json` was built before the script kept the Toronto Islands network, so its Island routes were repaired with [scripts/fix_island_routes.py](scripts/fix_island_routes.py), which also removes the rides between the mainland and the Islands (they went by ferry).

`public/data/day-2017-08-10.json` comes from [scripts/convert_2017.py](scripts/convert_2017.py), which places 2017 stations by name because those files have no station IDs, and then `build_day.py`.

To show a different day, change `DATA_URL` in [src/data.ts](src/data.ts). The script reads the 2024–2026 column layout; earlier years use different column names (see the docs).
